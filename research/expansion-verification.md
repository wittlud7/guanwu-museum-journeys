# 六城馆藏扩展核查

交付：`dist/expansion-data.js`，UMD `window.GUANWU_EXPANSION` / CommonJS，6 馆、18 件文物、21 张本地图片。

- 6 张馆舍资料图，15 张对应文物资料图。
- 暂缺同物许可照片：苏州秘色瓷莲花碗、苏州银奁、河南妇好鸮尊。这三条明确用馆舍图并注明不是文物照片，没有用其他藏品替代。
- 每件提供馆方/政府来源、原创简介、观察提示、问答与可朗读文本；没有将馆藏或历史照片表述为今天一定在展。
- 每馆有官方入口、地址、主题观看建议、3 段原创导览文稿。时长是产品建议，非馆方公布时长；观看顺序不是馆内导航路线。

## 事实来源

所有文物 source URL 已随数据交付。陕西历史博物馆的玛瑙杯、杜虎符和金碗藏品页；上海博物馆的大克鼎、子仲姜盘藏品页和商鞅方升专题；苏州博物馆官方必看藏品折页和莲花碗研究文章；湖北省博物馆的剑、钟、尊盘藏品页；河南博物院的骨笛、鸮尊、莲鹤方壶藏品页；湖南博物院马王堆陈列介绍与湖南省文旅厅介绍。

- 苏州银奁官方折页没有细分断代，本版不增加未经该来源证实的具体年代。
- 湖南素纱襌衣不采用混淆的 48/49 克数字，也不把有讨论的穿法写作定论。
- 玛瑙杯产地存在争议，未指定单一来源地。
- 未采用网络资料中“莲鹤方壶只有一件”“两件妇好鸮尊为同一件”等常见混淆。

## 图片核查

`research/expansion-image-credits.json` 保存图片文件名、作者、许可、许可链接、来源、原图 URL 与改动说明。全部图片为 Commons 的 CC0、Public domain 或 CC BY/CC BY-SA 图片；未采用无开放许可的馆方现代照片。`scripts/collect_expansion_images.py` 可检查已下载图片，并补下载清单里的缺失图片。

视觉核查重点：

- 金碗图与莲瓣纹样对应；子仲姜盘图中的立体水生动物对应；莲鹤方壶为河南博物院藏器来源。
- 帛画选用一号墓资料，未混入三号墓。
- Gary Todd 的 `Second Coffin` 局部图按由内向外计数，画面实际为朱地彩绘棺，因此本版改为 `vermilion-coffin`。主文明确第三层及朱红底色，不再误作黑地彩绘棺。
- 宝幢图片标题指瑞光寺塔，原始说明栏误写虎丘。本版按馆方资料解释为瑞光塔，并把来源问题及原件/复制件不确定写入 sourceRemarks。
- 大克鼎 API 缺机器可读作者，从原始 Commons 文件页核实为 Mountain，旋转裁切为 Meidosensei，已完整补入署名。

验证：Node 已实际 require UMD 文件，核对所有博物馆与文物的图片引用、18 个文物归属；Pillow 实际解码并 verify 21 个 JPEG。人工浏览联系表与金碗、莲鹤方壶、子仲姜盘、彩绘棺大图。
