# 微信原生小程序工程 · 城市博物馆版

使用微信开发者工具导入此目录。默认 AppID 为 `touristappid`，可选择测试号本地预览；正式发布前将其替换为自己的 AppID，并完成微信要求的认证、备案与审核。

原生WXML/WXSS/JavaScript，无第三方运行依赖，无需安装npm包。入口是 `pages/atlas/index`，城市详情与图片、MP3随对应城市分包加载，无需远程图片或语音域名。

覆盖11城80馆（北京50馆，其余每城3馆）、18件文物与8个工艺专题，新增22馆提供66个有来源的观察看点。“博物馆”用于选馆，“城市漫游”先浏览城市再选场馆，北京可从50家里搜索。支持城市/关键词筛选、系统大图预览、摄影来源、收藏、多馆行程与日期排序、观看手记、知识问答。`wx.setStorageSync`保存设备本地记录，`wx.setClipboardData`复制资料来源与行程。原有5馆提供音频，其余为阅读导览。跨馆对看、PNG观物卡与AI可在浏览器 `mini.html` 中体验，原生端尚未配置微信登录与专用AI网关，见根目录 DEEPSEEK.md。

原有5馆各3章语音，另有8段工艺讲解，均为AI合成普通话，并非真实戏曲唱段。支持暂停续播、拖动进度、倍速及文稿。入口主包约1.60MB，80个场馆分包、46个遗产阅读分包与10个语音资源分包，各约0.008—1.2MB，各低于2MB。首次到访需下载对应分包，下载成功后媒体可离线使用；客户端是否保留分包缓存仍由微信管理。

`credits.js`记录逐图署名、许可与链接。工艺参照图并非本馆现展藏品，页面分别标注。重新同步公共数据与媒体时运行 `python scripts/sync_native_assets.py`（在项目根目录）。`project.config.json`排除原版闲置的 `assets/`，新图片位于 `thumbs/` 与城市分包。

会员按钮演示免费权益解锁，未接真实收费、账号同步或票务。真实商业权益需要服务端鉴权与支付回调。地图、官方资料以复制链接或网页入口提供，不假装实时定位。

已通过JavaScript/JSON/WXML结构、模拟微信环境主要交互、媒体路径与分包体积检查。当前环境没有微信开发者工具，尚不能证明原生编译、渲染与真机音频已经通过；请导入后验收。网页对应功能已经通过浏览器检查。

网页和浏览器小程序预览另支持地图自定义路线、路线分享与另存、真实登录社区及管理员审核。当前原生工程尚未实现这些页面及微信登录/网关，不能把网页测试结果当作原生功能验收。

2026-10-26：新增完整46项世界文化/混合遗产，按省级地区浏览、搜索、阅读、收藏和记手记。原有23段讲解支持三种声音，第一次切换会调用 wx.loadSubpackage 加载对应声音和场馆分包；下载失败保留原声音。声音选择保存在本机。遗产页为文字阅读，三声简介与地图请在浏览器小程序预览体验。全部声明代码与媒体约22.06MB，单包均低于2MB；此体积检查不替代微信开发者工具编译和真机测试。
