# 微信原生小程序工程

使用微信开发者工具导入此目录。默认 AppID 为 `touristappid`，可选择测试号本地预览；正式发布前将其替换为自己的 AppID，并完成微信要求的认证、备案与审核。

原生 WXML/WXSS/JavaScript，无第三方依赖，无需安装 npm 包。图片随工程打包，不需要配置远程图片域名。主包小于 2 MB。

功能覆盖发现、分类搜索、4件真实文物介绍、收藏、长城漫游手记、行程保存、目的地选择和免费会员试读解锁。`wx.setStorageSync` 保存设备本地状态，`wx.setClipboardData` 复制藏品来源。

会员按钮只演示免费权益解锁。真实商业付费必须通过后端校验身份与支付回调，不能信任本地存储。当前无真实收费、服务端账号、实时位置、路线导航或票务。详情以真实馆藏照片为准，部分照片为馆方黑白档案图。

`assets/sources.json` 记录馆藏公共领域图像的来源。馆藏均位于纽约大都会艺术博物馆；观看提示为原创编辑。长城为主题照片，不代表某一入口。

已经通过 JSON、JavaScript 语法与模拟微信运行环境的主要交互检查。当前环境未安装微信开发者工具，原生渲染和真机效果仍需导入开发者工具验收；移动网页版本已经通过浏览器验证。
