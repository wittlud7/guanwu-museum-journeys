# 观物 · 城市博物馆指南

11 城 33 馆、18 件真实文物与 8 个工艺专题，连接影像、阅读、语音与 DeepSeek 随行伴游。浏览器小程序尺寸预览为 `mini.html`；微信原生工程在 `miniprogram/`。

2026-10-25 更新：现有每城增加两馆，新增22张对应许可照片、66个有来源的观察看点。“博物馆”用于按城市、主题、关键词选馆；“城市漫游”先选城市，再组合半天一馆或一天两馆。新增三组跨馆对看主题、18件文物的自由比较、观察手记和带图片署名的PNG观物卡导出。AI支持多馆组合与来源对照，不生成虚构馆内/馆间导航。核查清单见 `research/city-museums-verification.md`。

2026-10-24 更新：新增西安、上海、苏州、武汉、郑州、长沙。DeepSeek 已真实验证资料查询、来源回答和确认加入行程。新增场馆提供阅读导览；原有 23 段音频保留。三件文物缺可靠同物照片，清楚标注馆舍配图。接入与发布说明见 [DEEPSEEK.md](DEEPSEEK.md)。

本轮进一步加入地图与自定义路线：可调整多馆顺序、日期、开始时间、停留时长及自行预留的交通时间，保存后随时编辑；可分享路线，其他人可另存自己的版本。32馆有经核对的WGS84参考点，蜀锦织绣馆地址存在冲突，暂以地址检索代替。虚线仅表示游览顺序，实际道路路线由每一段的百度地图导航入口提供，时间表是个人预算。地图瓦片联网使用，不做离线下载。坐标依据见 `research/museum-locations-verification.md`。

“同行交流”使用服务端D1数据库保存真实帖子、回复、点赞与举报。访客可浏览，使用站点的ChatGPT登录后设置公开昵称并发帖；邮箱不公开。支持删除自己的内容、分享路线和管理员审核，不填充虚构用户或互动。个人行程、收藏和手记仍保存在当前浏览器，公开分享路线不包含私人日期和时间安排。

## 本地体验

运行 `node scripts/preview.mjs`，访问 http://localhost:4173/mini.html 。服务端读取私密配置，提供真实 AI 与音频字节范围请求。`settings.json` 已被 Git 忽略，禁止放进前端或发布资源。只需静态阅览时仍可使用 `python scripts/preview.py`，但不提供 AI 接口。离线下载需要 HTTPS 或 localhost。

完整社区本地调试使用 `server-app` 中的 `npm run dev`（默认5173），使用Sites开发环境的本地模拟登录及本地D1。4173预览仅提供资料和AI，不提供社区数据库。初始迁移位于 `server-app/drizzle/`，已应用的迁移及其元数据不可修改或重复执行；部署包包含迁移，由托管平台应用。管理员名单来自服务端Secret `COMMUNITY_MODERATOR_EMAILS`。

微信原生工程位于 `miniprogram/`，导入方式见其 README。网页首版的4件中国艺术开放馆藏保留在 `dist/classic/index.html`，可从“关于观物”进入。

## 可操作功能

- 11城33馆的城市/主题筛选、实时搜索与空状态；城市漫游支持一馆、两馆及自定义多馆地图路线。
- 真实社区发帖、回复、点赞、举报与本人删除；路线分享与另存，管理员可隐藏或恢复内容。
- 三组跨馆对看主题、18件文物自由比较；保存个人观察，并导出包含署名与来源的PNG观物卡。
- 大图浏览、缩放、拖移、双指缩放、键盘切图与摄影署名。
- 真实MP3播放、暂停、15秒前后跳转、进度拖动、0.8/1/1.2/1.5倍速、分章播放、续播记录、同步句子与文稿；跨页面维持单个播放器。
- 场馆和手艺收藏；多馆行程、排序、计划日期、复制清单；本地观看手记。
- 8道工艺小问答、错误重试与知识印记（不冒充实地打卡）。
- 免费首章与完整导览体验解锁；网页按馆下载图片与音频，支持断网后重载、阅读及播放。

## 来源与音频

场馆基础信息附馆方、政府、UNESCO或相关机构资料。文字与观察提示为原创编辑。`dist/assets/heritage/credits.json` 保存图片作者、原始链接、许可与处理说明，页面及微信详情均可查看。不同图片保留各自的CC许可，不能将许可误当成整应用统一授权。

语音为 `zh-CN-XiaoxiaoNeural`，以较舒缓的语速预生成，不依赖访客设备的系统声音。OpenAI语音生成曾因现有凭据401失败，本版使用 edge-tts 作为替代；没有把任何访客信息发送给语音服务。详见 `dist/assets/audio/manifest.json` 与 `scripts/build_audio.py`。界面明确标注为AI合成普通话，不是真人录音或戏曲唱段。正式商业运营应使用已确认相应使用条款的语音来源。

## 验证

运行 `node tests/native-guide.cjs`、`python tests/validate_assets.py`、`node tests/guide-server.mjs` 、`node tests/community-server.mjs` 和 `node tests/city-guide-server.mjs`。网页可用 Playwright CLI 执行 `tests/browser-guide.cjs`、`tests/browser-cities.cjs`、`tests/browser-cities-ai.cjs`、`tests/browser-route-planner.cjs`、`tests/browser-community.cjs`。地图自动化检查拦截瓦片请求，避免批量获取公共地图；社区写入仅在本地D1测试，未向生产社区添加测试内容。其中AI用例会产生少量真实模型请求，其他服务端测试用模拟传输。

浏览器检查覆盖四种宽度、13类页面、图片加载、真实音频播放/暂停/跳转/倍速、文稿、收藏/行程/手记/问答、断网下载与播放。另逐一解码23段MP3，检查时长、非静音、削波比例和字幕时间。微信端已检查JSON/WXML结构、逻辑适配、媒体路径和各分包大小；当前环境没有微信开发者工具，原生编译、渲染和真机音频仍待设备验收。

## 发布边界

会员解锁为不扣款的本地演示，不能用于商业鉴权。社区具有站点账号身份与云端保存；个人收藏、行程、手记尚未跨设备同步。当前没有真实微信支付、票务、室内定位或拍照识别。完整地图规划、社区、跨馆对看与AI在网页及浏览器小程序预览中提供；微信原生工程尚需微信登录、专用网关和相应页面接入。微信正式发布需自己的AppID与审核条件。
