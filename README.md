## 本地体验

运行 `node scripts/preview.mjs`，访问 http://localhost:4173/mini.html 。服务端读取私密配置，提供真实 AI 与音频字节范围请求。`settings.json` 已被 Git 忽略，禁止放进前端或发布资源。只需静态阅览时仍可使用 `python scripts/preview.py`，但不提供 AI 接口。离线下载需要 HTTPS 或 localhost。

完整社区本地调试使用 `server-app` 中的 `npm run dev`（默认5173），使用Sites开发环境的本地模拟登录及本地D1。4173预览仅提供资料和AI，不提供社区数据库。初始迁移位于 `server-app/drizzle/`，已应用的迁移及其元数据不可修改或重复执行；部署包包含迁移，由托管平台应用。管理员名单来自服务端Secret `COMMUNITY_MODERATOR_EMAILS`。

微信原生工程位于 `miniprogram/`，导入方式见其 README。网页首版的4件中国艺术开放馆藏保留在 `dist/classic/index.html`，可从“关于观物”进入。

## 可操作功能

- 11城80馆的城市/主题筛选、实时搜索与空状态；城市漫游支持一馆、两馆及自定义多馆地图路线。
- 真实社区发帖、回复、点赞、举报与本人删除；路线分享与另存，管理员可隐藏或恢复内容。
- 三组跨馆对看主题、18件文物自由比较；保存个人观察，并导出包含署名与来源的PNG观物卡。
- 大图浏览、缩放、拖移、双指缩放、键盘切图与摄影署名。
- 真实MP3播放、暂停、15秒前后跳转、进度拖动、0.8/1/1.2/1.5倍速、分章播放、续播记录、同步句子与文稿；跨页面维持单个播放器。
- 场馆和手艺收藏；多馆行程、排序、计划日期、复制清单；本地观看手记。
- 8道工艺小问答、错误重试与知识印记（不冒充实地打卡）。
- 免费首章与完整导览体验解锁；网页按馆下载图片与音频，支持断网后重载、阅读及播放。

## 来源与音频

场馆基础信息附馆方、政府、UNESCO或相关机构资料。文字与观察提示为原创编辑。`dist/assets/heritage/credits.json` 保存图片作者、原始链接、许可与处理说明，页面及微信详情均可查看。不同图片保留各自的CC许可，不能将许可误当成整应用统一授权。

语音使用 `zh-CN-XiaoxiaoNeural`、`zh-CN-YunxiNeural` 与 `zh-CN-XiaoyiNeural` 三种内置声音，以适合导览的语速预生成，不依赖访客设备的系统声音。OpenAI语音生成曾因现有凭据401失败，本版使用 edge-tts 作为替代；没有把任何访客信息发送给语音服务。旧版核心文稿清单见 `dist/assets/audio/manifest.json`；完整语音包使用 `scripts/build_voice_packs.py` 重建和核验，逐段测量见 `research/voice-packs-measurements.json`，说明见 `research/voice-packs-verification.md`。界面明确标注为AI合成普通话，不是真人录音或戏曲唱段。正式商业运营应使用已确认相应使用条款的语音来源。
