# 观物 · 博物与山河

移动端优先的博物馆藏与人文风景导览体验，无构建依赖。桌面端策展式布局，手机端底部导航。

## 本地运行

在项目目录运行 `python -m http.server 4173 --directory dist`，访问 http://localhost:4173。

## 已实现

- 发现首页、分类筛选、实时搜索、4件真实馆藏详情及资料来源。
- 浏览器本地收藏与行程持久化，长城观察手记，目的地选择。
- 浏览器语音朗读（依赖设备中文语音能力）。
- 免费简介、深度内容锁定、明确标注不扣款的免费会员演示。
- 手机适配、键盘焦点、弹窗关闭与减少动画偏好支持。

## 内容与版权

博物馆图像通过 The Met Open Access API 获取，下载时检查 isPublicDomain。来源与署名保存在 dist/assets/sources.json。中国艺术藏品实际收藏于纽约大都会艺术博物馆，页面明确说明。长城主题照片来自 Unsplash；它不代表具体游览入口。历史基础信息附馆方、UNESCO资料链接，观看提示为原创编辑内容。

## 上线边界与后续

此版本是移动网页原型，尚非微信原生小程序。上线微信需 AppID、备案与小程序工程；真实付费需后端账号、服务端权益校验、商户资质、支付回调及退款流程。前端本地会员状态只供体验，不能用于商业付费鉴权。

本地数据仅存当前浏览器，不跨设备同步。未接入实时位置、地图导航、票务或开放时间。当前内容规模为4件馆藏与1份漫游手记，后续应按实际合作机构扩充与校审，并确认各图片的商业使用授权。
